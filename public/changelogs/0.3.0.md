Detection Studio now evaluates your Sigma rules against uploaded sample data in real-time, entirely in the browser. Write a rule, upload your logs, and instantly see which events match.

The evaluation engine is [rsigma](https://github.com/timescale/rsigma) -- a Rust-based Sigma parser and evaluator compiled to WebAssembly, running in a background Web Worker so the UI stays responsive.

## New Features

- **Real-time Rule Evaluation** - Sigma rules are automatically evaluated against your sample data as you type, with results updating after a short debounce
- **JSON and NDJSON Support** - Upload sample data as a JSON array, single JSON object, or newline-delimited JSON
- **Pipeline Support in Evaluation** - Processing pipelines (field mapping, value transformations) are applied to rules before evaluation using rsigma's pySigma-compatible pipeline system
- **Filter Support in Evaluation** - Sigma filter rules from your workspace are applied as exclusion conditions on detection rules during evaluation
- **Field Coverage Analysis** - The evaluator detects when your Sigma rule targets fields that don't exist in your dataset and surfaces a warning with the specific missing field names, suggesting you add a processing pipeline
- **Redesigned Summary Tab** - Clear metric cards for Records, Matches, Match Rate, and File Size, with field analysis showing rule detection fields vs dataset fields at a glance

## Technical Highlights

- rsigma (v0.10.0) compiled to a 1.4MB WebAssembly binary (594KB gzip), running in a dedicated Web Worker
- Field names are extracted from the compiled rule detections post-pipeline, so field coverage analysis reflects the actual fields the engine searches for after transformations
- Evaluation re-runs reactively when any input changes: rule content, sample data, pipelines, or filters
